# キャラクター画像の置き場所

このフォルダに画像を置きます。

- ファイル名は `src/data/characters.ts` の `id` と対応させてください。
  - 例: `id: 'ch01'` → `ch01.png`
- 推奨サイズ: 256×256px 程度の正方形 PNG（背景透過でも可）
- コート上では円形に切り抜いて表示されます

画像が無い / 読み込めない場合は、色付きの丸＋番号のプレースホルダーが
自動で表示されます。あとから同じファイル名で置けばそのまま差し替わります。

## キャラクターを増やすとき

1. ここに `ch39.png` を追加
2. `src/data/characters.ts` の `CHARACTER_DEFS` に 1 行追加

```ts
{ id: 'ch39', name: '新キャラ' },
```

これだけで一覧・配置・PNG出力すべてに反映されます。
